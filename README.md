# Fratelli.skg Menu

Ένα επαγγελματικό project δημιουργίας ιστοσελίδας προβολής τιμοκαταλόγου μιας καφετερίας με την χρήση QR code. 

# Περιγραφή

Ένας τιμοκατάλογος όπου ο χρήστης μπορεί να αποκτήσει πρόσβαση στην ιστοσελίδα σκανάροντας το QR code του μαγαζιού. Ο χρήστης μπορεί να δει την τιμές των προϊόντων του καταστήματος. Επίσης μπορεί να μεταβεί στα social media του καταστήματος όπου βρίσκονται στο footer της ιστοσελίδας μαζί με άλλες χρήσιμες πληροφορίες σχετικές με την καφετέρια.

# Βασικά Χαρακτηριστικά

- Responsive σχεδιασμός για διαφορετικά μεγέθη οθόνης
- Χρήση CSS variables για τη διαχείριση χρωμάτων και styling
- Χρήση Navigation bar
- External links navigation
- Χρήση logo καταστήματος

# Τεχνολογίες 

- HTML5
- CSS
- JavaScript
